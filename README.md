# Kotonoha Sisters' Cyber Retro-Future Station

### [English Abstract]
This repository hosts source code and resources featured on the YouTube channel **"Kotonoha Sisters' Cyber Retro-Future Station."** We focus on SHARP Pocket Computers (e.g., PC-G850 series) and vintage computing, providing benchmarks, programming tutorials (C and BASIC), and technical demonstrations.

---

## 📺 チャンネルについて / About the Channel
YouTubeチャンネル「【ポケコン】琴葉姉妹の電脳レトロフューチャー局」の公式リポジトリです。
SHARP製ポケットコンピュータを中心に、レトロ技術の検証やプログラミングの楽しさを発信しています。

## 📁 フォルダ構成 / Directory Structure
動画プロジェクトごとにフォルダを分けて公開しています。

- **[common](./common/)**: 
  - 共通ツール置き場
- **[001_BasicVsC](./001_BasicVsC/)**: 
  - BASIC vs C言語 グラフィック描画速度比較テスト
- **[002_BasicVsC2](./002_BasicVsC2/)**: 
  - C言語 vs 機械語！限界突破の描画速度を体感せよ
- **[003_ExtSpeaker](./003_ExtSpeaker/)**: 
  - 200円のスピーカーでマリオのBEEP演奏に挑戦！
- **[004_ExtSpeaker2](./004_ExtSpeaker2/)**: 
  - C言語で魔界村！1bit BEEPの限界「3和音」への挑戦
- **[005_ExtSpeaker3](./005_ExtSpeaker3/)**: 
  - BASIC1ソースでドラクエ序曲！和音・ビープ・ロゴ全部入り計画
- **[006_SilverGlide](./006_SilverGlide/)**: 
  - 自作STG『SILVER GLIDE』完成
- **[007_SilverGlide_C](./007_SilverGlide_C/)**: 
  - C言語で爆速1ドットスクロール！「正攻法」で挑むSILVER GLIDE
